## Notes:

1. **Consistency**: All translations use consistent terminology across tabs
2. **Formality**: Uses informal "tú" form (common in Latin America)
3. **Technical Terms**: Some technical terms kept in English where appropriate (e.g., "CTA", "URL")
4. **Punctuation**: Spanish question marks use inverted opening mark (¿)
5. **Abbreviations**: "ej." for "ejemplo" (example), "máx" for "máximo" (maximum)
